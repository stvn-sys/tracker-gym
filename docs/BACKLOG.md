# Backlog — for the next version (do when the user asks for a new version)

## Muscle picker
- Drop the Choose primary / Add secondary switch. One list (and body map):
  single tap = set as primary, double tap = toggle as secondary.
  Show a short hint ("Tap = primary · double-tap = secondary").

## Reorder exercises mid-workout
- During a workout: "Reorder" (in the exercise ⋯ actions and/or header) opens a list of
  all exercises with move up/down (or drag); supersets move together. The current
  page follows the exercise you were on. "Save & update routine" keeps the new order.

## Swap in workout builder
- Workout builder: "Swap" in an exercise's ⋯ menu opens the exercise picker; the new
  exercise takes the same place, sets, rep range and superset.

## Assisted equipment
- Rename equipment "Band" to "Assisted", with sub-options Machine and Band.
  Assisted · Machine shows brand + series (same list as Machine, incl. "Other").
  Weight is logged as assistance (−kg). Move Bodyweight's "Assisted (machine)" /
  "Assisted (band)" variants here and migrate existing exercises. Non-assisted band
  exercises (band resistance, e.g. pull-aparts) move to Other.

## Attachments in the exercise editor
- Attachment field always available for equipment that can have one (with an "Other"
  chip like brands): typing a new one adds it to that equipment's attachment list in
  Settings and selects it. Show the field even when the list is still empty.

## Mini workout bar
- When you leave an active workout (back / minimize), show a compact bar docked above the
  tab bar on every tab, like a minimized music player: workout name, elapsed time, current
  exercise + set (e.g. "Lat Pulldown · set 2/3"), and the rest countdown when resting.
  Tap it to reopen the workout; small button to finish. Hidden when no workout is active.
